# Contributing to BahithX

Thank you for your interest in improving BahithX.

## Ways to Contribute

- Report bugs or unexpected behavior.
- Suggest new features.
- Add test cases and evaluation scenarios.
- Improve documentation and examples.
- Test the skill and share your findings.

## Before Contributing

For major changes, open an Issue first to discuss the proposal.

## Submitting Changes

1. Fork the repository.
2. Make your changes in your own fork.
3. Submit a Pull Request to the `main` branch.
4. Explain what changed and why.
5. Include relevant tests or evaluation results when applicable.

## Quality Standards

- Do not present assumptions as verified facts.
- Preserve unknown values instead of inventing data.
- Document conflicting evidence.
- Do not claim tests passed unless they were actually performed.
- Keep contributions focused and clearly documented.

## Review Process

All Pull Requests are reviewed before being merged. Maintainers may request changes before accepting a contribution.
